# Web search activity detail boundary

## Explicit selection and limits

Only `formatWebSearchQuery` and `extractWebSearchDetail` in
`packages/chat-core/src/tool-activity.ts` are selected. Their function-specific
annotations attribute compact query formatting and search/open/find detail to
the reference client. This is a bounded authoring selection under the explicit
cleanup request, not a finding that the whole module or every ordinary label
was copied. The baseline inventory retains the exact historical annotation and
declaration/module hashes. No exact recovered source binding has been located
in this pass; no source-rights or license conclusion follows.

## Requirements frozen before authoring

Preserve the synchronous public `extractWebSearchDetail(unknown)` contract and
its current string/null return values. Existing application tests require
single search text, multiple-query continuation, extracted site facets, an
open-page URL and a find-in-page pattern plus URL. Preserve precedence, whitespace,
unknown/malformed input behavior and ordinary output punctuation as compatibility
data, after observing the unchanged public port. Inputs must remain unchanged.

The existing Timeline projection owns protocol interpretation and call identity;
the tool presenter owns status, summary, grouping and expandability. The detail
projection must not execute a search, navigate, interpret a URL as trusted,
authorize a tool, mutate a call or select a provider. Web and Native keep the
same shared string contract. All adjacent helpers, presenters, failure policy,
content decoding, integration names and protocol constants stay unchanged.

Freeze complete raw outputs, including malformed fields, competing action
fields, arrays, Unicode/whitespace and site constraints before replacing the two
functions. Retain observer inputs and initial failures; do not change an
assertion to accept a candidate. Verify the existing tool/Timeline checks, Web
and Expo consumers, and actual browser presentation with synthetic protocol
data. No repository test or observation harness is added.

This requirements commit precedes implementation. The selected old bodies are
not printed for current authoring; broader prior author exposure remains
possible and recorded, so this is not strict author isolation. Historical
source and eight unresolved provenance groups remain open. Finite equivalence
does not establish historical rights or release readiness.
